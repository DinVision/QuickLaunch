Din Quick Launch Toolbar

Din Quick Launch Toolbar is a simple Windows 11/10 app with an auto-hide feature to manage shortcuts. It’s available on the Microsoft Store. See the YouTube video below for a quick demonstration.

Auto-Hide

To enable Auto-Hide, position the toolbar so it touches the side or top edge of the screen. The toolbar will then automatically hide when you move the mouse away from it.

Add and Group Shortcuts

The shortcuts for the toolbar are in the “Shortcuts” folder that can be opened as shown below. Create sub-folders to display shortcuts in separate groups as shown in the example. The 3-digit prefix is for sorting. The toolbar can be resized and moved as preferred.

Sorting and Naming the Shortcuts


For easy sorting, name the shortcuts with a 3-digit numeric prefix as below:
"010 Paint"
"020 Notepad"
"030 Excel"
If you need to insert new shortcuts in between, use an in-between numeric prefix, e.g.:
"015 Outlook"
The 3-digit numeric prefix is automatically hidden in the shortcut tooltip.

Website Shortcuts

To add shortcuts to specific websites, copy the shortcut of your browser (e.g., Edge). Open Properties, add the website address at the end of the Target value, and change the icon as preferred.

Run as Administrator

To run any app as an administrator, hold the Shift key while clicking the app icon.

Customization

The toolbar can be customized by modifying values in the INI file (see the demo video).

Troubleshooting

If you change INI settings and don’t have a backup, you can close the app, delete the INI file, and restart the app; it will re-create the INI file with default settings.

Background Image

To set a background image, enter the image file path in the BackgroundImagePath setting of the INI file (see example below). Use small image files (under 100 KB) to prevent slow loading. Close and reopen the app to apply changes.

How to change Toolbar Color

Change the color name for the ToolbarColor parameter (choose a color from the Color Names List). For example:
ToolbarColor=LightBlue
ToolbarBorder=Yes
ToolbarBorderColor=Green
Save the INI file, then close and re-open the toolbar to apply changes.

Create Icons

Use the Create Icon button to select image files (JPEG, PNG, BMP, GIF) and convert them to ICO files for your shortcuts. See this short video: Create Icons from Image.

Taskbar Display Setting

For older versions, if you prefer not to display the app in the Taskbar, set AlwaysShowOnTaskbar=No in the INI file. Restart the app. The app will be shown in the Taskbar only when minimized.
